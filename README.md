# IT Support & Networking Portfolio

Welcome to my IT Support and Networking portfolio.

This repository documents my hands-on learning journey in IT support, system administration, networking, and troubleshooting. It contains practical labs designed to develop technical skills through real-world-style scenarios, structured troubleshooting, and technical documentation.

## About This Portfolio

I am transitioning into the IT industry and building practical experience in Windows support, Linux administration, networking, and cybersecurity fundamentals.

My approach emphasizes systematic troubleshooting:

1. Identify the problem.
2. Gather relevant information.
3. Establish a baseline.
4. Investigate potential causes.
5. Test solutions safely.
6. Verify results.
7. Document findings.
